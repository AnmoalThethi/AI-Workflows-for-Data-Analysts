exploratory-data-analyst.md

Exploratory Data Analysis Skill

Embeds senior analyst rigor: hypothesis-first execution, confounding variable checks, and BLUF formatting.

Input: Python profile.py & CSV Output: BLUF Markdown

The 6-Step Analytical Methodology

Identify the exact business decision the analysis will inform and who is making it. Before writing queries, inspect internal context docs (such as Metrics Definitions) to prevent metric definition drift (e.g., confusing order-date with settlement-date).

Execute the companion Python profiling script on the dataset:

python3 ~/.claude/skills/exploratory-data-analyst/scripts/profile.py <path-to-csv>

Inspect row/column counts, missingness, duplicates, numeric distributions (IQR outliers), and date columns. Critical: Explicitly verify date parsing because Pandas often loads dates as raw object strings. Evaluate missingness non-randomly (e.g., dropped tracking events).

Formulate specific, falsifiable hypotheses. Select cuts of data explicitly designed to disprove the hypothesis. Always check for confounding variables (such as Simpson's Paradox or mix shifts across marketing acquisition channels). Rigorously distinguish between observational correlation and causal evidence.

Translate statistical variance into real-world business impact (e.g., “worth ~$420k annualized” or “impacts 1,400 collectors per month”). Transparently flag small sample sizes (n < 50) as directional noise rather than statistically definitive conclusions.

1. Answer One direct sentence answering the core decision question.
2. Evidence 2 to 4 key quantitative metrics carrying the argument.
3. Caveats Sample bounds, channel shifts, and data limitations.
4. Recommendation Concrete, evidence-backed action item for stakeholders.

Generate charts only when visual rendering conveys complex distributions or cohort transitions better than a clean markdown table. Always check if the environment has loaded the specialized dataviz.md skill to preserve palette and typographic standards.

Non-Negotiable Rules for EDA Analysts

Never report aggregate metrics without verifying underlying audience definitions.
Never let headline numbers stand without testing plausible confounds (e.g. channel mix).
Never present observational correlation as causal proof for strategic choices.
Never bury conclusion takeaways at the end of a long narrative walkthrough.

metrics-anomaly-watch.md

Metrics Anomaly Watch Skill

Monitors monthly business CSVs against organizational guardrails to catch material inflection points.

Triggers: "check for anomalies", "red flags" Strict 17-Col Schema

Core Logic: Status-Quo Baseline vs. Trend Acceleration

The skill does not flag established, long-term trends as anomalies. For instance, if Bigstart Collectibles’ M3 retention rate has steadily declined over 18 months, that gradual decline is the established baseline. An anomaly is flagged only if the rate of decline accelerates relative to its trailing 3-month average.

Required 17-Column CSV Schema
month, status, sessions, orders, revenue_usd, aov_usd, new_customers, paid_new_customers, paid_marketing_spend_usd, paid_cac_usd, conversion_rate_pct, repeat_order_share_pct, m1_second_purchase_pct, m3_second_purchase_pct, gross_margin_pct, refund_rate_pct, email_opt_in_pct
Crucial Filter Rule: Must execute status == 'Actual' to prevent poisoning actual trends with forward forecast Plan rows!

Real-World Execution Guardrails

Common Gotchas & Troubleshooting Rules

Gmail Filter

Unread Status vs. Awaiting Reply

Avoid using is:unread to surface action items. Unread status captures newsletters and junk while missing read-but-unanswered emails. Instead, use the last-sender heuristic (newer_than:7d where last sender ≠ user).

Gmail Filter

Automated Sender Pollution

Always explicitly drop automated notification senders (no-reply@, accounts.google.com, GitHub bots) to prevent zero-value notifications from cluttering focus digests.

Google Drive

Escaped Quotes in Frontmatter

YAML frontmatter status values are quoted (status: "Draft"). Drive searches must escape inner quotes: query: "fullText contains 'status: \"Draft\"'" Omitting escapes silently returns zero records!

Google Drive

Org Chart Multi-Table Parsing

Org Chart documents partition staff across Leadership, Analytics team, and Core product partners. The AI agent must scan all three tables before marking an attendee unlisted. Also gracefully handle missing email history rather than crashing execution.

Calendar

Explicit TimeZone Parameters

Always supply an explicit IANA timeZone string (e.g., America/New_York). Failing to do so causes MCP connectors to default to UTC, shifting boundaries and returning meetings on the wrong day.

Calendar

Recurring Series Event IDs

Recurring event instances return compound IDs formatted as <seriesId>_<timestamp>. Never deduplicate these entries, as each represents an active, independent meeting instance.

Analytics Data

Actual vs. Plan Mixing

Business CSVs combine past Actual results with Plan forecasts. Always explicitly filter status == 'Actual' prior to calculating deltas, otherwise forecast targets will pollute historical trend lines.

Analytics Data

Metric Directionality Rules

Directional value is metric-specific. Increases in CAC or refund rates are negative/adverse, whereas increases in gross margin or repeat order share are positive. Guardrails must encode this polar logic.

Analytics Data

Correlation vs. Causation Guard

Never report observational associations as causal proof for strategic decisions. Always isolate mix shifts (channel shifts, cohort seasonality) and Simpson’s Paradox before certifying a finding.

Evolution of the Role

The Human-AI Hybrid Analytics Model

The data analyst role is shifting from manual execution (writing boilerplate SQL, copying data across sheets, drafting meeting recaps) to that of an Architect who designs, audits, and maintains an enterprise library of AI skills.

Continuous Refactoring Lifecycle for Skill Files

Step 1 Generate Initial Template

Run an automated skill generator to establish the baseline structure, role, and markdown contracts.

Step 2 Execute on Real Tasks

Deploy the skill against real operational requests (e.g. CEO retention inquiries, live morning briefs).

Step 3 Evaluate Output Gaps

Audit output for hallucinated metrics, loose summaries, or missing confounding variable evaluations.

Step 4 Refine Skill.md Rules

Tighten instructions directly in the markdown file (e.g., enforce P0/P1 tables, add non-negotiable clauses).

Handled by Modular AI Agent
  • Automated multi-channel data extraction via MCP
  • Mechanical schema profiling & IQR outlier discovery
  • Trailing email triage & last-sender heuristics
  • First-pass BLUF report drafting and structured tables
High-Leverage Human Focus
  • Formulating core business decisions & falsifiable hypotheses
  • Auditing causal vs correlational validity
  • Cross-functional leadership and executive strategy
